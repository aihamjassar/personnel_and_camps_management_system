# نظام إدارة شؤون الأفراد والمعسكرات:

مشروع أكاديمي لإدارة السجلات الإدارية الأساسية باستخدام React, TypeScript, Express, Prisma وPostgreSQL. **استخدم بيانات افتراضية فقط**؛ لا تُدخل بيانات حقيقية أو حساسة. الواجهة تدعم العربية واتجاه RTL.

## المتطلبات

- Node.js 20 أو أحدث وnpm.
- PostgreSQL محلي للتطوير والاختبارات.

## الإعداد المحلي

1. ثبّت الاعتمادات من جذر المستودع:

   ```bash
   npm ci
   ```

2. انسخ قالب إعداد الخادم وأنشئ قاعدة بيانات التطوير:

   ```bash
   cp server/.env.example server/.env
   createdb personnel_camps
   ```

   عدّل `DATABASE_URL` و`JWT_SECRET` في `server/.env` بما يلائم بيئتك. استخدم سر JWT قويًا خارج بيئة التطوير.

3. طبّق الترحيلات وأضف بيانات العرض الأكاديمية:

   ```bash
   npm run db:deploy -w server
   npm run db:seed -w server
   ```

4. شغّل واجهة React وخادم API معًا:

   ```bash
   npm run dev
   ```

   الواجهة متاحة افتراضيًا على `http://localhost:5173`، والخادم على `http://localhost:4000` مع API تحت `/api/v1`.

## الحساب التجريبي

بعد تشغيل التهيئة والـseed المحلي، حساب العرض الافتراضي هو `admin / Admin@1234`. **هذا الحساب مخصص للتطوير فقط ويجب تغييره قبل أي نشر**. يُحفظ رمز الجلسة في `sessionStorage`، ولا ينبغي استخدام بيانات دخول حقيقية في العرض الأكاديمي.

## الفحوص والبناء

```bash
npm run typecheck
npm test
npm run build
```

تشغّل `npm test` مجموعة الاختبارات على قاعدة منفصلة اسمها `personnel_camps_test`، ويقوم إعداد الاختبار بإعادة ضبط مخطط هذه القاعدة. جهّز قاعدة اختبار محلية معزولة للمشروع، ولا توجّه إعداد الاختبار إلى قاعدة تطوير أو إنتاج تحتوي على بيانات مهمة. البيانات التي تُنشئها اختبارات التكامل اصطناعية.
