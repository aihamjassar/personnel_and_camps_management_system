# ملحق المراجعة الهندسية لدراسة الجدوى

**التاريخ:** 2026-10-05
**حالة الوثيقة:** ملحق مبني على مستودع المشروع المتاح؛ ليس النسخة المنقحة من دراسة الجدوى الأصلية.

## حدود المراجعة

تذكر [`Implement-Plan.md`](Implement-Plan.md) أن خطة المشروع مشتقة من «دراسة الجدوى الشاملة لمشروع التخرج رقم 21 — جامعة تعز / قسم تقنية المعلومات»، لكن نص الدراسة الأصلية الكامل غير موجود ضمن ملفات المستودع التي تمت مراجعتها. لذلك لا يمكن التحقق من افتراضاتها الاقتصادية أو تحليل المخاطر الأصلي أو اعتماد هذا الملحق على أنه تحديث رسمي للدراسة. يقتصر هذا الملحق على تقييم الجدوى التقنية والتشغيلية وفق نطاق المتطلبات والشفرة والاختبارات والوثائق المتاحة.

## الخلاصة

| البعد | النتيجة المتاحة | الدليل / الشرط المفتوح |
|---|---|---|
| الجدوى التقنية | **متحققة محليًا على مستوى نسخة أكاديمية**: بنية React/Express/Prisma/PostgreSQL، وحدات FR-01–FR-16، و50 اختبارًا ناجحًا | [`Requirements-Traceability.md`](Requirements-Traceability.md)، [`Testing-Report.md`](Testing-Report.md). لا يعني ذلك اختبار قبول كاملًا أو جاهزية إنتاجية. |
| سلامة البيانات | **ضوابط أساسية منفذة**: قيود مرجعية، ترحيلات، معاملات ذرية للنقل والتعيين، سجل حالات وتدقيق، RBAC | يلزم مراجعة بشرية مستقلة واختبار المتصفح متعدد الأدوار. |
| الأمن | **غير جاهز للتعرض العام** | 7 تحذيرات في شجرة الإنتاج (3 عالية و4 متوسطة) حسب آخر `npm audit --omit=dev`؛ يلزم خطة ترقيات متوافقة واختبارها قبل النشر. |
| التشغيل والاستضافة | **حزمة نشر قابلة للنقل معدّة، لكن لا توجد بيئة حية** | لا مضيف دائم ولا نطاق DNS مخوّل في المستودع. Sandbox مؤقت ولا يستضيف قاعدة دائمة. |
| HTTPS | **غير متحقق حيًا** | Caddy مهيأ لإصدار TLS بعد ربط النطاق وفتح المنافذ؛ لا توجد شهادة أو تجربة وصول عام مثبتة. |
| النسخ والاستعادة | **الآلية المحلية معدة واختبار التشفير/الفك نجح** | لا جدولة Docker فعلية ولا تخزين خارج الموقع/مالك تشغيلي أو اختبار استعادة على مضيف إنتاجي. |
| الجدوى الاقتصادية | **غير قابلة للتحديث من الأدلة الحالية** | لا تتضمن الملفات المتاحة ميزانية، أسعار استضافة، تقدير تشغيل أو تحليل تكلفة/منفعة مفصلًا. يلزم نص الدراسة والافتراضات الأصلية. |
| النطاق والبيانات | **محدد كنسخة تجريبية أكاديمية** | استخدام بيانات اصطناعية فقط. لا تستخدم لإدارة أفراد حقيقيين أو بيانات حساسة/عسكرية. |

## شروط التوصية

يوصى بتسليم النسخة كإنجاز برمجي أكاديمي **محلي غير منشور**. قبل أي عرض على شبكة عامة، يلزم: مراجعة الاعتمادات وإصلاحها، مراجعة فريق مستقلة، اختبار قبول كامل بالمتصفح، تحديد مضيف ونطاق ومالك تشغيل، اختبار TLS من خارج الشبكة، ونقل النسخ إلى تخزين خارج الموقع مع تجربة استعادة موثقة.
