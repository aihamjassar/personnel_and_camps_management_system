# Memory — ملف الذاكرة المرجعية للمشروع

> هذا الملف يُقرأ أولًا في بداية أي جلسة عمل (بشرية أو مع نموذج ذكاء اصطناعي) لاستعادة كامل سياق المشروع بسرعة دون الحاجة لإعادة شرح كل شيء من الصفر. يجب تحديثه كلما تغيّر قرار مهم أو اكتملت مرحلة.

---

## 1. هوية المشروع

- **الاسم:** نظام إدارة شؤون الأفراد والمعسكرات
- **بالإنجليزية:** Integrated Personnel and Camps Management System
- **الجهة:** جامعة تعز — كلية الحاسوب وتقنية المعلومات — قسم تقنية المعلومات
- **النوع:** مشروع تخرج رقم 21 — دراسة جدوى شاملة (المستوى الرابع)
- **طبيعة البيانات:** بيانات افتراضية بالكامل لأغراض أكاديمية — **لا** تتضمن أي معلومات عسكرية أو حساسة حقيقية

## 2. القرارات المعمارية الثابتة (لا تُغيَّر دون مراجعة صريحة)

| القرار | القيمة | السبب |
|---|---|---|
| نمط المعمارية | Modular Monolith (Layered) | يناسب فريقًا طلابيًا وجدولًا زمنيًا 16 أسبوعًا |
| الواجهة الأمامية | React.js SPA | — |

## 3. نطاق المشروع (لا يتم تجاوزه)

**Must-Have (MVP):** إدارة الأفراد، إدارة المعسكرات، إدارة المستخدمين، المصادقة والصلاحيات الأساسية، التعيينات، واجهات API الأساسية، قاعدة البيانات، لوحة تحكم رئيسية، تقارير أساسية.

**Should-Have:** إدارة الانتقالات الكاملة، سجلات التدقيق الكاملة، البحث المتقدم، التقارير القابلة للتصدير.

**Could-Have (لاحقًا، خارج الـ16 أسبوعًا):** تحليلات متقدمة، تكاملات مع أنظمة خارجية، إشعارات فورية.

**Won't-Have (خارج النطاق نهائيًا):** أي وظائف تشغيلية أو عسكرية حقيقية، أو تعامل مع بيانات سرّية أو حساسة فعلية.

> ⚠️ أي طلب مستقبلي يقع ضمن "Won't-Have" يجب رفضه أو تحويله لملاحظة في "التطويرات المستقبلية" فقط، وليس تنفيذه.

## 7. قواعد ثابتة يجب تذكّرها دائمًا

1. لا حذف فعلي لأي سجل فرد — التعطيل منطقي (Soft Delete) فقط.
2. حالة الفرد (`PersonnelStatus`) تُحفظ تاريخيًا تراكميًا، لا تُكتب فوق السجل القديم.
3. عملية النقل بين المعسكرات **يجب** أن تكون معاملة قاعدية موحّدة (Transaction) — لا حالات نصف منفّذة.
4. كل عملية حسّاسة تُسجَّل تلقائيًا في `AuditLogs` من طبقة التكامل، وليس من الواجهة.
5. لا نقطة API تُستثنى من التحقق من الصلاحية (RBAC) — حتى لو بدت "غير حساسة".
6. أي تعديل معماري جوهري يجب أن يُسجَّل أولًا هنا (القسم 2) قبل التنفيذ.
