# هيكلة صفحات النظام (Website / Application Structure)

> نظرًا لكون النظام تطبيق ويب إداري (وليس موقعًا تسويقيًا)، الهيكلة هنا مبنية على **لوحة تحكم (Dashboard-based SPA)** بدلًا من صفحات تسويقية تقليدية. تم تضمين جزء مبسّط لصفحة الهبوط (Landing/Login) لأنها نقطة الدخول الوحيدة العامة.

---

## 1. الخريطة العامة للتطبيق (Sitemap)

```
/ (صفحة الدخول - Login)
│
└── /app  (بعد المصادقة - Protected Routes)
    │
    ├── /dashboard              ← لوحة التحكم الرئيسية (FR-12)
    │
    ├── /personnel              ← إدارة الأفراد (FR-01, FR-02, FR-03, FR-04)
    │     ├── /personnel/new
    │     ├── /personnel/:id
    │     └── /personnel/:id/edit
    │
    ├── /camps                  ← إدارة المعسكرات (FR-05)
    │     ├── /camps/new
    │     └── /camps/:id
    │
    ├── /units                  ← الوحدات التنظيمية (FR-06)
    │     └── /units/:id
    │
    ├── /ranks-positions        ← الرتب والمناصب (FR-07)
    │
    ├── /assignments            ← التعيينات (FR-08)
    │
    ├── /transfers              ← إدارة الانتقالات (FR-09)
    │     ├── /transfers/new
    │     └── /transfers/:id
    │
    ├── /users                  ← إدارة المستخدمين (FR-10)
    │     └── /users/:id
    │
    ├── /roles-permissions      ← الأدوار والصلاحيات (FR-11)
    │
    ├── /reports                ← التقارير الإدارية (FR-13)
    │     └── /reports/summary
    │
    ├── /audit-logs             ← سجلات التدقيق (FR-14) — مدير النظام فقط
    │
    ├── /notifications          ← الإشعارات (FR-15)
    │
    ├── /settings               ← إعدادات النظام (FR-16) — مدير النظام فقط
    │
    └── /profile                ← الملف الشخصي للمستخدم الحالي
```

---

## 2. هيكل صفحة تسجيل الدخول (Login Page)

```
Header
  └── شعار النظام + اسم النظام (نظام إدارة شؤون الأفراد والمعسكرات)
Body
  └── نموذج تسجيل الدخول
        ├── حقل اسم المستخدم
        ├── حقل كلمة المرور
        ├── زر "تسجيل الدخول"
        └── رسالة خطأ (عند الفشل)
Footer
  └── جامعة تعز — قسم تقنية المعلومات (بيانات مشروع تخرج)
```

## 3. هيكل الصفحة الداخلية العامة (Layout Template)

كل الصفحات داخل `/app` تتبع نفس القالب:

```
┌─────────────────────────────────────────────┐
│  Topbar: اسم المستخدم | الدور | الإشعارات 🔔 │
├───────────┬─────────────────────────────────┤
│           │                                 │
│  Sidebar  │        Main Content Area        │
│  (قائمة   │   (يتغيّر حسب المسار الحالي)     │
│  التنقل   │                                 │
│  حسب الدور)│                                 │
│           │                                 │
└───────────┴─────────────────────────────────┘
```

### عناصر الـ Sidebar (تظهر/تختفي حسب صلاحيات الدور — RBAC):

| العنصر | الأدوار المصرح لها |
|---|---|
| لوحة التحكم | الجميع |
| إدارة الأفراد | ضابط شؤون الأفراد، مدير النظام |
| إدارة المعسكرات | مدير النظام، الإدارة المركزية |
| الوحدات التنظيمية | مدير الوحدة، مدير النظام |
| التعيينات والانتقالات | ضابط شؤون الأفراد، مدير المعسكر |
| المستخدمون والصلاحيات | مدير النظام فقط |
| التقارير | الإدارة المركزية، مستعرض التقارير |
| سجلات التدقيق | مدير النظام فقط |
| الإعدادات | مدير النظام فقط |

## 4. تفصيل صفحة "إدارة الأفراد" (كمثال تطبيقي)

```
/personnel
├── شريط أدوات علوي: [بحث متقدم] [+ إضافة فرد جديد] [تصدير]
├── جدول الأفراد (Pagination)
│     الأعمدة: الاسم الكامل | الرتبة | الوحدة | الحالة | إجراءات
└── نافذة منبثقة/صفحة فرعية للتفاصيل والتعديل
      ├── بيانات أساسية
      ├── سجل التعيينات (تبويب)
      ├── سجل الانتقالات (تبويب)
      └── السجل التاريخي للحالة (تبويب)
```

---

## 5. ملاحظة SEO (خارج نطاق النظام الإداري)

كما ظهر في ملاحظات العصف الذهني، أي حاجة لصفحة تسويقية عامة (Home / About) مستقلة عن لوحة التحكم تُعامل كمشروع فرعي منفصل (موقع تعريفي)، وليست جزءًا من نطاق نظام إدارة شؤون الأفراد والمعسكرات نفسه — ولا يُنصح بخلطها في نفس الـ Sitemap لتفادي تشتيت الوحدات.
