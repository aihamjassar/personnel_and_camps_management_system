# خطة التنفيذ (Implementation Plan)
## نظام إدارة شؤون الأفراد والمعسكرات — Integrated Personnel and Camps Management System

> المصدر: دراسة الجدوى الشاملة لمشروع التخرج رقم 21 — جامعة تعز / قسم تقنية المعلومات

---

## 1. نظرة عامة على المشروع

نظام معلومات إداري متكامل قائم على الويب (Web-Based Information System) يجمع إدارة شؤون الأفراد والمعسكرات ووحداتها التنظيمية تحت منصة مركزية واحدة، بحيث تتواصل جميع الوحدات الوظيفية عبر واجهات برمجية موحدة (APIs) بدلًا من الاعتماد اليدوي على الملفات.

**نمط المعمارية المعتمد:** Modular Monolith بتصميم طبقي (Layered Design) — الخيار الموصى به في دراسة الجدوى نظرًا للفريق الطلابي المحدود والجدول الزمني (16 أسبوعًا).

**نطاق البيانات:** بيانات إدارية افتراضية بالكامل، لأغراض تجريبية أكاديمية بحتة — لا تتضمن أي معلومات تشغيلية أو عسكرية أو حساسة حقيقية.

---

## 2. طبقات النظام (من الحل المقترح ومعمارية النظام)

| الطبقة | التقنية/الوصف |
|---|---|
| العميل (Client) | React.js SPA — متصفح الويب |
| الواجهة الأمامية / العرض | لوحات التحكم، النماذج، التقارير المرئية |
| API (REST / JSON) | المصادقة، الموجّه، معالجة الطلبات |
| منطق الأعمال (Business Logic) | قواعد الأفراد، المعسكرات، الانتقالات، الصلاحيات |
| طبقة التكامل (Integration Layer) | تنسيق الاتصال بين الوحدات + سجل التدقيق |
| طبقة البيانات (Database Layer) | PostgreSQL — جداول الأفراد، المعسكرات، المستخدمين... |

---

## 3. الوحدات الوظيفية الرئيسية (Modules)

1. **إدارة الأفراد** (تسجيل، تعديل، بحث، حالة الفرد)
2. **إدارة المعسكرات** (بيانات، سعة، موقع افتراضي)
3. **إدارة الوحدات التنظيمية** (الهيكل التنظيمي)
4. **إدارة الرتب والمناصب**
5. **إدارة التعيينات** (ربط فرد بمنصب/وحدة)
6. **إدارة الانتقالات** (نقل الأفراد بين المعسكرات)
7. **إدارة المستخدمين والأدوار والصلاحيات** (RBAC)
8. **لوحة التحكم الرئيسية** (Dashboard)
9. **التقارير الإدارية** (PDF/Excel)
10. **سجلات التدقيق** (Audit Log)
11. **الإشعارات** (Notifications)
12. **إعدادات النظام**

## 4. مراحل التنفيذ (Phases) — مبنية على الجدول الزمني الفعلي (16 أسبوعًا)

### 🔵 Phase 0 — الإعداد والتوثيق الأساسي (الأسابيع 1–6)
- جمع وتحليل المتطلبات (وظيفية/غير وظيفية)
- تحديد النطاق والمعمارية العامة
- تصميم قاعدة البيانات (ER + قاموس البيانات)
- تصميم واجهات المستخدم (Wireframes)
- **المخرجات:** جميع ملفات `docs/*.md` (هذه الوثائق)

### 🟢 Phase 1 — الوحدات الأساسية (Must-Have / MVP) (الأسابيع 7–9)
- إدارة الأفراد، إدارة المعسكرات، إدارة المستخدمين والمصادقة الأساسية
- التعيينات، واجهات API الأساسية، قاعدة البيانات الفعلية
- لوحة تحكم رئيسية، تقارير أساسية

### 🟡 Phase 2 — التكامل والصلاحيات (الأسابيع 10–11)
- تكامل الأنظمة بين الوحدات (تدفق بيانات موحد)
- تطوير المصادقة الكاملة (JWT) والصلاحيات (RBAC)

### 🟠 Phase 3 — الميزات المتقدمة (Should-Have) (الأسبوع 12)
- إدارة الانتقالات الكاملة بين المعسكرات
- سجلات التدقيق الكاملة (Audit Log)
- البحث المتقدم والتقارير القابلة للتصدير (PDF/Excel)

### 🔴 Phase 4 — الاختبار والتوثيق والنشر (الأسابيع 13–16)
- الاختبار الشامل (وحدة، تكامل، نظام)
- التوثيق الفني ودليل المستخدم
- النشر التجريبي (Deployment)
- المراجعة النهائية والعرض التقديمي

> ملاحظة: الميزات ضمن **Could-Have** (تحليلات متقدمة، تكاملات خارجية، إشعارات فورية) تُعتبر خارج النطاق الحالي وتُذكر فقط في "التطويرات المستقبلية"، ولا تُنفَّذ ضمن الأسابيع الـ16.

## 5. فريق العمل والأدوار

| الدور | المسؤوليات |
|---|---|
| مدير المشروع / محلل النظم (Project Manager / Analyst) | تنسيق الفريق، جمع المتطلبات، متابعة الجدول الزمني |
| مطوّر الخلفية (Backend / API Developer) | تطوير منطق الأعمال، بناء واجهات REST، ربط قاعدة البيانات |
| مطوّر الواجهة الأمامية (Frontend / UI Developer) | تصميم وتطوير واجهات المستخدم وربطها بواجهات API |
| مهندس تكامل الأنظمة والمعمارية (Systems Integration / Architecture Engineer) | تصميم معمارية التكامل، تنسيق تدفق البيانات بين الوحدات |
| مهندس قاعدة البيانات / الجودة / الأمان (Database / QA / Security Engineer) | تصميم قاعدة البيانات، اختبار حالات الاختبار، تطبيق الضوابط الأمنية |

## 6. معايير القبول العامة للمشروع (مختصر من المتطلبات غير الوظيفية)

- زمن استجابة أقل من 2 ثانية لـ 95% من الطلبات
- تشفير HTTPS لجميع الاتصالات، تجزئة كلمات المرور (bcrypt)
- توثيق شامل + فصل واضح للوحدات + تغطية اختبار لا تقل عن 70%
- توافق أساسي مع معايير WCAG لإمكانية الوصول
- نسخ احتياطي دوري مجدول
