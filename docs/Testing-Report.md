## إعادة التشغيل

من جذر المستودع، وبعد ضبط `server/.env` لاتصال PostgreSQL محلي مخصص للاختبار:

```bash
npm ci
npm test
npm run coverage
npm run typecheck
npm run build
git diff --check
```

يولّد `npm test` و`npm run coverage` Prisma Client تلقائيًا. ينتج Vitest تقريري HTML وLCOV تحت `server/coverage/`؛ المخرجات مولّدة ومتجاهلة في Git.

> **تحذير:** إعداد الاختبارات يعيد مخطط قاعدة `personnel_camps_test` قسرًا. لا توجّه `server/.env` إلى قاعدة تطوير أو عرض أو إنتاج تحتوي على بيانات تحتاجها.

## ما لم يثبت بعد

- نُفذ smoke test يدوي محدود للمتصفح يغطي الدخول واللوحة وقراءة إعدادات المدير؛ ما زال اختبار قبول شامل عبر المتصفح لكل الأدوار والسيناريوهات ومراجعة إمكانية الوصول غير منفذ. مصفوفة التتبع تصف الأدلة لكل متطلب وحدودها.
- قياس التغطية للخادم فقط؛ بعض وحدات التشغيل/الربط لا تُنفذ في اختبار الوحدة المعتاد.
- تحققنا من إعداد Compose وسكربت النسخ والترحيلات، لكن لم تُبنَ صورة Docker ولم تُشغّل خدمات Compose لعدم توفر Docker engine في Sandbox.
- لم تُنشر البيئة ولم يُختبر HTTPS على نطاق حي. يلزم مضيف دائم ونطاق DNS مخول واختبار من شبكة خارجية. النسخ الحالي على volume محلي فقط؛ يلزم تحديد تخزين خارج الموقع ومالك يختبر الاستعادة.
- لا تثبت الاختبارات ملاءمة النظام لبيانات حقيقية أو تشغيل إنتاجي؛ النطاق المعلن يستخدم بيانات اصطناعية فقط.
