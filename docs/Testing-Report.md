# تقرير الاختبارات — 2026-10-03

## النطاق والبيئة

- النطاق: خادم API والوحدات الخلفية في نظام إدارة شؤون الأفراد والمعسكرات.
- البيانات: اصطناعية أكاديمية فقط.
- قاعدة التكامل: `personnel_camps_test` منفصلة عن قواعد التطوير والإنتاج، وتُعاد تهيئتها قسرًا قبل كل تشغيل للاختبارات.
- الأدوات المتحققة: Node.js 22، PostgreSQL 16، Vitest 3 مع V8 coverage.

تغطي الاختبارات المصادقة ورفض الحساب المعطّل، RBAC، إدارة الأفراد وحفظ تاريخ الحالة والحذف المنطقي، البيانات المرجعية والتعيينات، النقل الذري والتحقق من السعة ووحدة الوجهة والتزامن، تغييرات الصلاحيات وحماية آخر مدير نظام، إدارة المستخدمين، التدقيق وتحديد معدل الدخول، الإشعارات، وتصدير PDF وExcel.

## طريقة إعادة التشغيل

بعد تثبيت الاعتمادات وإعداد `server/.env` باتصال PostgreSQL محلي خاص بالاختبارات وسر JWT محلي:

```bash
npm test
npm run coverage
npm run typecheck
npm run build
```

`npm test` و`npm run coverage` يولّدان Prisma Client تلقائيًا قبل التشغيل. يكتب Vitest تقرير HTML وLCOV في `server/coverage/`؛ هذه الملفات مولّدة ومتجاهلة بواسطة Git.

## حدود التحقق الحالية

- هذه نتائج اختبارات تكامل API على الخادم، وليست تغطية مستقلة لكل مكوّن واجهة ولا اختبار متصفح شاملًا لكل حالات الاستخدام.
- معيار 70% مفروض على **تغطية الأسطر**؛ تغطية الفروع الحالية 62.93% وتبقى تحسينًا لاحقًا، خصوصًا للفروع غير المختبرة في بعض المسارات.
- لا تثبت هذه الاختبارات جاهزية نشر عام، أو HTTPS، أو إعداد نسخ احتياطية دورية. لم يُنشر التطبيق ولم تُستخدم بيانات حقيقية.

## مراجعة الاعتمادات

أظهر `npm audit` **15 تحذيرًا** (8 عالية و7 متوسطة، دون حرجة) في شجرة الاعتمادات. جُرّب `npm audit fix` دون `--force` ولم تتوفر إصلاحات ضمن نطاقات الإصدارات الحالية؛ الإصلاحات المقترحة تتطلب تغييرات رئيسية لبعض الاعتمادات الأساسية، مثل Prisma وTailwind وReact Router وVitest وExcelJS. لم تُطبّق ترقيات مكسِّرة بلا مراجعة توافق. يجب فرز هذه التحذيرات واختبار الترقيات ضمن مراجعة أمنية منفصلة قبل أي نشر.
